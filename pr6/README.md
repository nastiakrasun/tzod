# 📱 Аналіз прискорення під час ходьби та бігу за допомогою акселерометра смартфона

## 📌 Опис

У проєкті реалізовано збір, обробку та аналіз даних акселерометра смартфона з використанням мобільного додатку phyphox та мови програмування Python.

Було проведено експеримент із вимірювання прискорення під час:
- спокійної ходьби
- швидкої ходьби
- бігу

Отримані дані були експортовані у форматі CSV, оброблені за допомогою бібліотеки pandas та візуалізовані з використанням matplotlib.

---

## 🎯 Мета

- Отримати реальні дані з акселерометра смартфона
- Дослідити зміну прискорення при різних типах руху
- Виконати фільтрацію шуму в даних
- Побудувати графіки прискорення
- Визначити середнє прискорення для кожного режиму руху

---

## 📂 Дані

Часовий ряд містить:

- **Time (s)** — час вимірювання
- **Absolute acceleration (m/s²)** — абсолютне значення прискорення

Дані були зібрані за допомогою мобільного додатку phyphox на iPhone.

---

## ⚙️ Методологія

Для обробки даних використано:

- бібліотеку **pandas** для аналізу CSV-файлу
- бібліотеку **matplotlib** для побудови графіків

Було виконано:

1. Завантаження даних із CSV
2. Фільтрацію шуму методом ковзного середнього
3. Поділ експерименту на три ділянки:
   - спокійна ходьба
   - швидка ходьба
   - біг
4. Обчислення середнього прискорення
5. Побудову графіків

Для згладжування даних використано метод ковзного середнього.

---

## 📈 Результати

Отримані середні значення прискорення:

- Спокійна ходьба — 1.588 м/с²
- Швидка ходьба — 3.126 м/с²
- Біг — 5.739 м/с²

Було побудовано:
- графік зміни прискорення у часі
- стовпчикову діаграму середніх значень

Аналіз показав, що зі збільшенням темпу руху середнє прискорення зростає.

## 🧠 Висновок

Акселерометр смартфона дозволяє ефективно аналізувати рухову активність людини.

Отримані результати демонструють чітку залежність між типом руху та величиною прискорення.

Метод фільтрації шуму дозволив зменшити випадкові коливання та покращити якість аналізу даних.
